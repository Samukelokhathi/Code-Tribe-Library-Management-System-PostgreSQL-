# Code-Tribe-Library-Management-System-PostgreSQL-

A Library Management System built using PostgreSQL to practice relational database management, SQL queries, and managing library resources such as books, authors, and patrons.
This project focuses on understanding how databases work, creating tables, inserting records, retrieving information, updating data, deleting records, and performing advanced SQL queries.


## 🎯 Use-Case Scenario

Imagine a library that needs to keep track of its books, authors, and patrons.

A librarian should be able to:
- Add new books to the library.
- Register authors.
- View available books.
- Search for books by title or author.
- Mark books as borrowed or returned.
- Update patron borrowing records.
- Remove outdated records.
- Run SQL queries to analyze library information.

# 💻 Installation and Setup

## 1. Install PostgreSQL

Download PostgreSQL from the official website:

🔗 https://www.postgresql.org/download/


### Windows Installation

1. Download the PostgreSQL installer.
2. Run the installer.
3. Follow the installation instructions.
4. Select the PostgreSQL Server and pgAdmin 4 components if offered.
5. Set a password for the PostgreSQL database superuser.
6. Keep note of the password you create.
7. Complete the installation.
